Raw customer screenshots for the landing page proof wall.

Drop the file here, then add one entry to PROOF_SCREENSHOTS in lib/landing.ts:

    { src: "/proof/screenshots/<filename>", alt: "...", caption: "..." }

Any aspect ratio works — the wall lays them out in masonry columns and shows
each at its own shape.

Published exactly as supplied. Whatever is in the frame goes on a public,
indexed page: the sender's full name and profile photo, any certificate
legible in their photo, and any of our own tooling caught in the shot.
